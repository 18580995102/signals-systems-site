Formula Manual

可搜索、可复制的公式手册

覆盖三大变换、卷积、奇偶虚实、尺度时移频移、微分/差分方程、系统性质判据、抽样定理和课程高频公式。

傅里叶变换核心性质

ℱ{x(t − t0)} = e−jωt0X(jω) ℱ{x(at)} = 1|a|X(jω/a) ℱ{x(t) ∗ h(t)} = X(jω)H(jω)

时移只改相位，尺度压缩会拉宽频谱，卷积在频域变乘法。

拉普拉斯与系统函数

X(s) = ∫−∞∞ x(t)e−stdt H(s) = Y(s)X(s) 因果系统的 ROC 在最右极点右侧；稳定系统的 ROC 包含 jω 轴。

ROC 是拉普拉斯题目的灵魂，决定信号类型、因果性和稳定性。

Z 变换与单位圆判据

X(z) = ∑n=−∞∞ x[n]z−n H(z) = Y(z)X(z) 稳定系统的 ROC 包含单位圆 |z| = 1；因果稳定 IIR 的极点在单位圆内。

频率响应可由 H(e^{jω}) 得到，也就是在单位圆上观察 H(z)。

抽样定理与混叠

fs ≥ 2fmax,   T = 1fs x(t) = ∑n=−∞∞ x(nT)sinc(t − nTT)

欠采样会使频谱副本重叠，离散样值无法唯一恢复原连续信号。

线性判据

T{a x1(t) + b x2(t)} = aT{x1(t)} + bT{x2(t)} 若 x1(t) → y1(t), x2(t) → y2(t) 则 ax1(t)+bx2(t) → ay1(t)+by2(t)

线性必须同时满足齐次性与叠加性；有常数项、平方、绝对值通常会破坏线性。

时不变 / 时变判据

若 x(t) → y(t) 则 x(t − t0) → y(t − t0) 对任意 t0 成立时，系统为时不变系统。

判断方法：先延时输入再过系统，与先过系统再延时输出比较；显含 t 的系数常导致时变。

因果性与记忆性

y(t0) 只依赖 x(t), t ≤ t0 ⇒ 因果 y[n0] 只依赖 x[n], n ≤ n0 ⇒ 因果 LTI 因果条件：h(t)=0, t<0；h[n]=0, n<0

若输出用到未来输入，如 x(t+1) 或 x[n+2]，系统非因果。

BIBO 稳定判据

|x(t)| ≤ Mx ⇒ |y(t)| ≤ My 连续 LTI：∫−∞∞|h(t)|dt < ∞ 离散 LTI：∑n=−∞∞|h[n]| < ∞

BIBO 稳定强调有界输入产生有界输出；对 LTI 系统可转化为冲激响应绝对可积/可和。

稳态、暂态与全响应

y(t) = yzi(t) + yzs(t) y(t) = ytr(t) + yss(t) 稳定系统中：limt→∞ ytr(t) = 0

零输入由初始状态引起，零状态由外加输入引起；暂态随时间衰减，稳态长期保留。

正弦稳态与频率响应

x(t)=Acos(ω0t+φ) yss(t)=A|H(jω0)|cos(ω0t+φ+∠H(jω0)) 离散：H(ejΩ) 在单位圆上取值。

稳定 LTI 系统对正弦输入的稳态输出仍为同频率正弦，只改变幅度和相位。

无记忆与动态系统

连续：y(t0) 只由 x(t0) 决定 ⇒ 无记忆 离散：y[n0] 只由 x[n0] 决定 ⇒ 无记忆 若用到 x(t−1), x(t+1), x[n−2] 等，则为有记忆系统。

无记忆不等于因果；因果允许依赖过去输入，无记忆只允许依赖当前输入。

可逆性与逆系统

若不同输入必产生不同输出，则系统可逆。 存在 T−1{·}，使 T−1{T{x}} = x LTI 频域：若 H(jω) ≠ 0，则可构造 Hinv(jω)=1H(jω)

平方、绝对值、限幅等操作常把多个输入映射到同一输出，因此通常不可逆。

Python：FFT 频谱分析

NumPy/Matplotlib 版本，适合科研入门和工程仿真快速验证。

import numpy as np
import matplotlib.pyplot as plt

fs = 200
t = np.arange(0, 1, 1/fs)
x = np.sin(2*np.pi*12*t) + 0.4*np.sin(2*np.pi*36*t)
X = np.fft.rfft(x)
f = np.fft.rfftfreq(len(x), 1/fs)

plt.subplot(2,1,1); plt.plot(t, x); plt.title("time domain")
plt.subplot(2,1,2); plt.stem(f, np.abs(X)); plt.title("FFT spectrum")
plt.tight_layout(); plt.show()

MATLAB：卷积与系统响应

用于验证 LTI 系统输出 y(t)=x(t)*h(t)，也可替换成离散 conv。

t = -2:0.001:6;
dt = t(2)-t(1);
x = double(t>=0 & t<=1);
h = exp(-t).*(t>=0);
y = conv(x, h, 'same') * dt;

plot(t,x,'b',t,h,'--',t,y,'r','LineWidth',1.5);
legend('x(t)','h(t)','y(t)');
grid on; title('Convolution response');

频谱控制

FFT 把 N 点序列投影到一组复指数基底上，频谱峰值表示对应频率的能量强弱。

DFT: X[k]=Σx[n]e^-j2πkn/N FFT 将 O(N²) 计算降为 O(N log N)。

Z 变换把序列 x[n] 映射到复平面 X(z)，极点位置决定系统响应是否收敛。

当前表达式X(z)=1/(1-a z^-1)
收敛域 / 稳定性|z| > |a|，极点在单位圆内，因果系统稳定。

Z 平面极零图

蓝色圆为单位圆，红叉为极点，绿色圆为空心零点。
H(z)=1/(1-a z^-1) 极点越靠近单位圆，响应衰减越慢；极点落到单位圆外时系统不稳定。
